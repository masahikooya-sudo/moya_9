# 日程調整アシスタント（Gmail アドオン）

バイヤー・サプライヤーとの打ち合わせ日程を、**Gmail の右サイドバーから**調整する Google Workspace アドオンです。
社内の複数人の Google カレンダーの空きを確認して候補日を仮押さえし、打診メールや確定メールの**下書き**まで自動で作成します。

## できること

| # | 機能 | 内容 |
|---|------|------|
| 1 | 候補日の抽出 | 開いたメールから候補日時を自動抽出（`9/15（月）13:00〜14:00`、`9月15日 13時〜14時半`、全角数字、1行に複数枠などに対応）。手入力での追加も可 |
| 2 | 社内の空き確認 | 自分＋選択した社内参加者の Google カレンダーを Free/Busy で確認し、候補ごとに「全員空き / ○名が予定あり / 確認不可」を表示 |
| 3 | こちらから候補を提示 | 期間・時間帯・所要時間・候補数を指定すると、全員が空いている枠を自動で探索（土日・祝日・昼休みの除外に対応） |
| 4 | 仮押さえ | 選んだ候補をカレンダーに `【調整中】` で仮押さえ（社内参加者も招待してブロック可能） |
| 5 | 打診メールの下書き | 候補日を打診するメールを、件名ルールに沿って返信の下書きとして作成。ボタン 1 つで作成画面が開きます |
| 6 | 確定の検出 | 先方の返信（例：「9/16でお願いします」）から確定した候補を自動で推定 |
| 7 | 確定処理 | カレンダーを `【確定】` に更新して他の候補を削除、**Google Meet / Zoom / Microsoft Teams** の会議URLを発行、確定メールの下書きを作成 |

### 件名ルール

```
【調整中】【Web】ABC商事｜新製品案件｜田中バイヤー
【確定】【訪問】XYZ工業｜部品調達｜佐藤サプライヤー
【確定】【訪問・一部Web】ABC商事｜新製品案件｜田中バイヤー
```

- 状態：`調整中` / `確定`
- 形式：`訪問` / `訪問・一部Web`（訪問で一部の参加者が Web 参加）/ `Web`
- 会社名・案件名・担当者（姓）＋立場（バイヤー / サプライヤー / 様）
- 書式は「設定」の件名テンプレートで変更できます（`{status}` `{mode}` `{company}` `{project}` `{contact}` `{role}`）。

## 画面の流れ

```
[先方から候補日が届いた場合]
 メールを開く ─▶ ① 候補日の抽出 ─▶ ② 案件情報 ─▶ ③ 社内の参加者を選択 ─▶ [空き状況を確認]
              ─▶ 候補ごとの空き状況 ─▶ ④ 仮押さえ / CC の選択 ─▶ [候補日を送る（下書きを作成）]
              ─▶ [下書きを開いて編集・送信]

[こちらから候補日を出す場合]（「新規で作成」タブ、またはメールを開いていないときのホーム画面）
 宛先・案件情報・参加者・検索条件 ─▶ [全員の空きから候補日を探す] ─▶ 以降は上と同じ

[先方から確定の返信が届いた場合]
 返信メールを開く ─▶ 「このメールから確定のご連絡を検出しました」
              ─▶ カレンダー更新 / 会議リンク（Meet・Zoom・Teams・手入力）/ 確定メール下書き ─▶ [日程を確定する]
```

- 返信が合わなかった場合は「候補日を出し直す」で仮押さえを削除して再検索できます。
- サイドバー右上のメニュー（︙）から「進行中の日程調整」「設定」を開けます。

## セットアップ

### 1. Apps Script プロジェクトを作成してコードを配置

[clasp](https://github.com/google/clasp) を使う場合:

```bash
npm install -g @google/clasp
clasp login
clasp create --type standalone --title "日程調整アシスタント" --rootDir src
# 既存のプロジェクトを使う場合は .clasp.json.example を .clasp.json にコピーして scriptId を設定
clasp push
```

clasp を使わない場合は、[script.google.com](https://script.google.com/) で新しいプロジェクトを作り、`src/` の各 `.js` ファイルを同名の `.gs` ファイルとして貼り付け、
「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにして `src/appsscript.json` の内容で置き換えます。

### 2. Google Cloud プロジェクトの設定

組織内で利用する場合は、標準の Google Cloud プロジェクトに紐づけることを推奨します。

1. Google Cloud コンソールでプロジェクトを作成し、**Google Calendar API / Gmail API / People API** を有効化
2. OAuth 同意画面を **内部（Internal）** で作成
3. Apps Script の「プロジェクトの設定」→「Google Cloud Platform（GCP）プロジェクト」でプロジェクト番号を設定

> 高度なサービス（Calendar / Gmail / People）はマニフェストで有効化済みです。

### 3. Gmail にインストール

- **自分だけで試す**：Apps Script エディタ →「デプロイ」→「デプロイをテスト」→「Google Workspace アドオン」→「インストール」
- **組織全体に配布**：Google Workspace Marketplace SDK で「非公開（社内限定）」として公開し、管理コンソールから対象ユーザーにインストール（手順は [docs/DEPLOY.md](docs/DEPLOY.md)）

### 4. 初期設定

Gmail のサイドバーでアドオンを開き、右上メニュー（︙）→「設定」で以下を登録します。

- 自社名・自分の氏名・署名（メール本文に使用）
- 社内ドメイン（外部メールの判定に使用）
- よく使う社内メンバー（1行に1人：`山田 花子 <yamada@example.co.jp>`）
- 既定の所要時間・時間帯・先方の立場・ビデオ会議ツール

## ビデオ会議の設定

| ツール | 必要な設定 |
|---|---|
| Google Meet | 不要（カレンダー予定に Meet を自動追加） |
| Zoom | 管理者が Server-to-Server OAuth アプリを作成し、スクリプト プロパティに登録 |
| Microsoft Teams | 管理者が Microsoft Entra ID にアプリを登録し、スクリプト プロパティに登録 |
| その他 | 確定画面で URL を手入力 |

スクリプト プロパティは Apps Script エディタの「プロジェクトの設定」→「スクリプト プロパティ」で設定します（全利用者で共有されます）。

### Zoom

1. [Zoom App Marketplace](https://marketplace.zoom.us/) で **Server-to-Server OAuth** アプリを作成
2. スコープに `meeting:write:meeting:admin`（旧スコープの場合は `meeting:write:admin`）を追加して有効化
3. スクリプト プロパティを登録

| キー | 値 |
|---|---|
| `ZOOM_ACCOUNT_ID` | Account ID |
| `ZOOM_CLIENT_ID` | Client ID |
| `ZOOM_CLIENT_SECRET` | Client Secret |
| `ZOOM_USER_ID`（任意） | 会議のホストにする Zoom ユーザー（メールアドレス）。未設定時は利用者の Google アカウントのメールアドレス |

### Microsoft Teams

1. Microsoft Entra 管理センターでアプリを登録し、クライアント シークレットを発行
2. API のアクセス許可に Microsoft Graph の **アプリケーションの許可** `OnlineMeetings.ReadWrite.All` を追加し、管理者の同意を付与
3. Teams 管理者が [アプリケーション アクセス ポリシー](https://learn.microsoft.com/graph/cloud-communication-online-meeting-application-access-policy) を作成し、会議の主催者となるユーザーに付与
4. スクリプト プロパティを登録

| キー | 値 |
|---|---|
| `TEAMS_TENANT_ID` | ディレクトリ（テナント）ID |
| `TEAMS_CLIENT_ID` | アプリケーション（クライアント）ID |
| `TEAMS_CLIENT_SECRET` | クライアント シークレット |
| `TEAMS_ORGANIZER_ID`（任意） | 主催者のユーザー ID または UPN。未設定時は利用者の Google アカウントのメールアドレス |

## 仕様・注意点

- **空き確認**：Google カレンダーの Free/Busy を使うため、予定の中身は参照しません。カレンダーが共有されていない人は「確認不可」と表示されます。
- **仮押さえ**：自分のカレンダーに黄色の `【調整中】` 予定を作成します。「社内参加者も仮押さえに招待」をオンにすると、参加者のカレンダーにも（通知なしで）入り、他の予定が入るのを防げます。確定時に、確定した候補以外は自動で削除されます。
- **件名とスレッド**：件名を変更して返信するため、Gmail 上で元のスレッドと別スレッドになる場合があります。アドオンは元のスレッドと作成した下書きのスレッドの両方を記録し、さらに件名（会社名・案件名）からも調整中の案件を探すので、どちらのスレッドで返信が届いても確定の操作ができます。
- **自動抽出・自動検出**はルールベースの推定です。必ず画面で内容を確認してから送信してください（下書き作成までで、メールは自動送信しません）。
- 「1時〜2時」のように午前・午後の指定がない 1〜7 時は、業務時間とみなして 13〜19 時と解釈します。
- 権限：下書きの作成とスレッドの読み取りに Gmail の `https://mail.google.com/` スコープを使います（制限付きスコープのため、社内限定での配布を想定しています）。
- データ：調整中の案件は利用者ごとの UserProperties に保存されます。作成途中のものは 14 日、確定済みのものは 90 日で自動削除されます。

## 開発

```bash
npm test        # 解析ロジックの単体テスト＋モック環境での一連のフローの結合テスト
npm run check   # 構文チェック
```

### ファイル構成

```
src/
  appsscript.json     マニフェスト（スコープ・トリガー・高度なサービス）
  Main.js             トリガーとボタンのアクション、フォーム入力の反映
  Cards.js            サイドバーのカード UI
  Parser.js           候補日時の抽出・確定連絡の検出・案件情報の推定（純粋関数）
  Slots.js            空き判定・共通の空き枠探索（純粋関数）
  Templates.js        件名・メール本文・表示文字列（純粋関数）
  CalendarService.js  Free/Busy・仮押さえ・確定（Calendar API）
  Conference.js       Zoom / Teams の会議作成
  MailService.js      メールの読み取り・下書き作成（Gmail API）
  Store.js            調整セッションの保存
  Settings.js         ユーザー設定・スクリプト プロパティ
tests/                Node.js のテスト（Apps Script サービスはモック）
```
